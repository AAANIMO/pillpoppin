# Pillpoppin — Guide

**Pillpoppin** is an image mangler: it reads your image as if it were *audio*,
lets you stack audio-style DSP effects on it (volume, distortion, pitch, delay,
EQ…), and renders the glitched result back to a picture. Everything runs locally
— no upload, no account, works fully offline.

- [Usage](Usage.md) — the workflow, step by step
- [Shortcuts](Shortcuts.md) — keyboard shortcuts
- [Install](Install.md) — download & open on macOS / Windows

*An animosity project featuring pasticca.*

## Quick start

1. **Start pillpoppin** from the splash.
2. **Load an image** (PNG / JPG / TIFF).
3. **Add effects** from the right rail into the chain.
4. The **AFTER** preview updates live as you tweak parameters.
5. **APPLY** to bake the current chain into a new layer, then keep mangling.
6. **Export** as PNG / JPG / TIFF.
