# Keyboard shortcuts

On macOS use **⌘ (Cmd)**; on Windows use **Ctrl**.

| Action | macOS | Windows |
|--------|-------|---------|
| Undo | ⌘Z | Ctrl+Z |
| Redo | ⇧⌘Z or ⌘Y | Ctrl+Shift+Z or Ctrl+Y |
| Apply chain | ⌘Enter | Ctrl+Enter |
| Close dialog | Esc | Esc |
| Start app (on splash) | Enter / Space | Enter / Space |

## Window (from the menu bar)

- Toggle fullscreen, zoom in / out / reset, reload, and dev tools are available
  under the **View** menu.
