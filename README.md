# Pillpoppin

**Image mangler** — a glitch & databending tool for images. Load a picture,
stack effects into a chain, watch the result update live, and export PNG / JPG / TIFF.
Fully offline, self-contained, no account.

*An animosity project featuring pasticca.*

## Download

Grab the latest build from the [Releases](https://github.com/AAANIMO/pillpoppin/releases/latest) page:

| Platform | File |
|----------|------|
| macOS (Apple Silicon) | `Pillpoppin-arm64.dmg` |
| macOS (Intel)         | `Pillpoppin-x64.dmg` |
| Windows               | `Pillpoppin-x64.exe` |

The app is unsigned. On macOS, right-click the app → **Open** the first time (or
System Settings → Privacy & Security → *Open Anyway*). On Windows, click
**More info → Run anyway** on the SmartScreen prompt.

## Run from source

```bash
npm install
npm start          # launch the app
npm run dist:mac   # build a .dmg (macOS)
npm run dist:win   # build an .exe (Windows)
```
